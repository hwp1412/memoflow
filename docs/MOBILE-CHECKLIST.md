# MemoFlow 真机验收清单

> 第一阶段的代码层已经允许 `isDesktopOnly: false`。但“能加载”不等于“已验证”，请按下面清单在对应设备上逐项打勾；未跑过的平台在交付说明中标记为「未验证」。

## 0. 通用准备

- [ ] Obsidian 版本 ≥ 1.12.7（桌面与移动端都看一遍）。
- [ ] 使用 `MemoFlow-Test/` 测试 Vault，不碰真实 `supermemo` 库。
- [ ] 测试 Vault 中 **只启用 MemoFlow**，不要同时启用 `incremental-reading-toolkit`。
- [ ] 插件目录：`<vault>/.obsidian/plugins/memoflow/{main.js,manifest.json,styles.css}`。
- [ ] 如果是移动端，先把整个 `MemoFlow-Test/` 文件夹同步/拷贝到设备可访问位置（iCloud Drive、Files、Android 本地存储等），再用 Obsidian「打开文件夹作为 Vault」。

## 1. 启动与入口

- [ ] 设置 → 第三方插件中能看到 **MemoFlow 0.1.0**，可启用且无报错。
- [ ] 左侧 ribbon 出现清单图标，tooltip 为「MemoFlow：学习面板」。
- [ ] 命令面板搜索「MemoFlow」能找到「打开 MemoFlow 学习面板」。
- [ ] 点击后打开一个名为 **MemoFlow** 的标签页，不是空白页。
- [ ] 关闭再打开标签页，页面仍能正常渲染。

## 2. 页面布局

- [ ] 竖屏/横屏各看一次；没有横向滚动条，没有文字被裁切。
- [ ] 在 iPad 分屏（PDF + MemoFlow）中，页面仍可滚动、可点击。
- [ ] 390px 左右宽度（手机）下：Hero、队列、最近摘录、学习节奏、负荷、树、来源依次堆叠。
- [ ] 触控目标不拥挤：队列行、chips、PDF 按钮都能稳定点中。
- [ ] iOS 安全区/Android 系统栏没有遮住页面底部（页脚可见或不影响操作）。

## 3. 真实数据

- [ ] 今日数字与测试 Vault frontmatter 一致：只跑 `seed-test-vault` 时是 4 个来源、8 条摘录、2 张卡片；跑完整工作流会再增加 1 个书籍来源、1 条摘录、1 张卡片。
- [ ] 逾期/今日到期/新素材/卡片四个数字与队列筛选结果一致。
- [ ] 队列行显示标题、来源、优先级、到期与间隔；点击能打开对应笔记。
- [ ] 「开始今日学习」构建/使用今日 session，并打开第一项实际内容：PDF 来源用 Obsidian 原生 PDF（定位 read_point），Markdown 用笔记+阅读条。
- [ ] 「打开阅读队列」打开上游 Reading queue 侧栏。
- [ ] 知识树展开/收起、点击节点能打开笔记。
- [ ] 最近摘录显示正文摘要与来源；点击能打开。
- [ ] 阅读中来源显示页码进度与摘录数量。

## 3.5 阅读操作条与时间戳摘录

- [ ] 从 PDF/笔记回到文件列表后打开，或在文件列表打开 session 中的摘录/来源，顶部有「今日队列 · 1 / 7」操作条。
- [ ] 阅读视图与实时预览两种模式都能看到操作条。
- [ ] 「完成并下一项」把当前摘录标记 done，并打开下一项。
- [ ] 来源笔记的「评阅并下一项」能走完页码/间隔评阅，再打开下一项。
- [ ] 「跳过」只前进，不把当前笔记移出队列。
- [ ] 点「延后」出现 +1 / +3 / +7 天选项，选择后当前笔记改期并前进。
- [ ] 「移出队列」把当前笔记标记 dismissed 并前进。
- [ ] 标题栏的「MemoFlow 阅读操作」图标也能打开同一组操作。
- [ ] 队列里有卡片时，卡片笔记顶部显示「下一项 / 复习此卡」，而不是完成/延后按钮。
- [ ] 命令面板「生成时间戳摘录（选中 / 剪贴板）」生成 `YYYY-MM-DD HH-mm-ss.md`。
- [ ] 新摘录底部有 `**来源**：[[...pdf#page=N|...]]`，点击能回到 PDF 对应页。
- [ ] 剪贴板里带 `#page=` 或 PDF 注释链接时，页码/选区参数被带入引用。

## 3.6 中文界面与卡片闭环

- [ ] 设置 → MemoFlow：关于/阅读排程/队列/内联卡片/SR/知识树/路径/通用全部中文；A-Factor、FSRS、Spaced Repetition 等技术词保留。
- [ ] 设置左侧导航能看到 MemoFlow；SR 也出现在同一个「第三方插件」区。
- [ ] 环境状态显示「Spaced Repetition 已就绪」；「运行环境检查」输出中文。
- [ ] 命令面板里上游 9 个命令都是中文；命令 ID / 原有快捷键仍有效。
- [ ] 「采集或新建…」「当前阅读项操作…」「打开 MemoFlow 视图…」「高级工具…」四个菜单条目是中文。
- [ ] 打开一条摘录，阅读条点「制卡」；基础问答填写问题/答案后生成 `... - Card N.md`。
- [ ] 切到 Cloze，答案区隐藏；`==关键词==` 能生成 cloze 卡；缺少 `==` 时不关闭弹窗并提示。
- [ ] 新卡 frontmatter 有 `type: card`、`source`、`flashcards/incremental-reading`；正文是 SR 的 `?` 或 `==` 格式。
- [ ] 卡片阅读条「复习此卡」打开 SR；显示答案 → 评分后卡片正文出现 `<!--SR:...-->`。
- [ ] 总览页显示「卡片待复习」；点「卡片复习」进入只含卡片的卡片复习页。
- [ ] 禁用 SR 后总览显示「卡片（需 SR）」、复习按钮禁用；制卡仍可用但提示先安装。

## 3.7 完整工作流（书籍）

- [ ] 运行 `npm run seed:book` 后，测试库出现 `被讨厌的勇气` 来源（265 页，PDF 在 `test/`）。
- [ ] 打开来源，阅读条显示 `P…` 与 `p.N / 265`；点页码打开 PDF 阅读点。
- [ ] 「评阅并下一项」选 Hold 并输入页码，`read_point`、`interval`、`next_review`、`review_count` 更新。
- [ ] 从该来源生成时间戳摘录，页脚带 `被讨厌的勇气.pdf#page=N`。
- [ ] 从摘录制作基础问答/Cloze 卡片，SR 评分后出现 `<!--SR:...-->`。
- [ ] 阅读条优先级 chip 可设 P1–P100 或提升 5/15/30，frontmatter/队列更新。
- [ ] 总览「过载处理」选 Mercy 窗口后，逾期数下降/归零。
- [ ] 真实 `supermemo` 库与 HWP 知识仓库全程没有打开/修改。

## 3.8 队列优先级 / 子集复习 / 自动过载

- [ ] 总览队列行的 `P…` chip 可点击（卡片除外）；修改后行内数字立即变化，frontmatter 同步。
- [ ] 队列筛选/搜索后出现「复习筛选（N）」；点击后 session 只包含筛选结果，并打开第一项。
- [ ] 设置 → 阅读排程 → 自动过载：打开并设阈值；逾期超过阈值时开始今日学习，逾期被自动按 7 天摊平。
- [ ] 自动过载关闭后，开始学习不再写日期，仅保留手动「过载处理」。

## 3.9 完整 i18n

- [ ] 阅读页「评阅并下一项」：页码、质量选项（保持/提前/推后）、确定/取消均为中文。
- [ ] 新建来源：来源标题、来源类型（书籍/文章/PDF/YouTube/本地视频）、总页数、收件箱确认均为中文。
- [ ] 使用指南、设置页、命令名、顶层菜单全中文。
- [ ] 常用成功/错误 Notice 为中文（开始队列、评阅、摘录、制卡、Mercy 等）。
- [ ] 控制台异常堆栈和第三方 SR 界面仍是英文，属于预期范围。

## 3.10 开始学习 / 卡片复习

- [ ] 总览「开始今日学习」按 session 逐项打开实际内容；PDF 顶部有横向 MemoFlow 功能栏。
- [ ] 总览「卡片复习」只出现问答/Cloze 卡片，不混入主题。
- [ ] 制卡弹窗有 C1/C2/C3 插入按钮和挖空数量提示；C1/C2/C3 保存为 SR 多挖空卡，开始学习逐张出现。
- [ ] PDF 来源用原生阅读器打开并定位页码；功能栏的「制卡」在阅读阶段灰显，「剪贴摘录」可用。
- [ ] Markdown 来源/摘录有完整阅读条；问答卡片顶部只保留卡片动作，主题按钮置灰。
- [ ] 卡片评分后进度前进，SR 卡片正文出现/更新 `<!--SR:...-->`。
- [ ] 复习卡片时没有可见的 SR deck 弹窗，也没有多出来的临时卡片标签。
- [ ] 关闭开始学习/卡片复习后，隐藏的 SR 会话被清理。
- [ ] SR 不可用时卡片项降级为打开原笔记，不崩溃。

## 4. 搜索、筛选、排序

- [ ] 搜索框输入「提问」能过滤队列与树；清空后恢复。
- [ ] 全部/阅读/摘录/卡片/逾期 chips 计数与筛选正确。
- [ ] 排序切换紧急度 / 优先级 / 到期日会改变队列顺序。
- [ ] 无匹配时显示「没有匹配项」，不白屏。
- [ ] `⌘K` / `Ctrl+K` 能聚焦搜索框；Esc 清空或关闭菜单。

## 5. 示例数据

## 6. 移动端 PDF（关键）

- [ ] 关闭 PDF 后回到页面无异常。

- [ ] 桌面端（macOS/Windows）点同一按钮仍走原 Toolkit viewer；Vault 外 PDF 在桌面可正常打开。

## 8. 错误与恢复

- [ ] 断网/重启 Obsidian 后页面仍能加载本地数据。
- [ ] Review Log 为空时学习节奏显示「完成一次阅读评分后开始记录」，其他区块正常。
- [ ] 打开一个没有 frontmatter 的笔记再回到 MemoFlow，页面不报错。
- [ ] 控制台（Cmd+Option+I / 移动端调试）没有红色 `[MemoFlow]` 错误。

## 已知限制（不是缺陷）

- 移动端不能打开 Vault 外 PDF；这是 Obsidian 移动端没有 Node 文件系统的限制。
- 平板/桌面都优先用「剪贴摘录」；页码取当前 PDF 页，找不到再回退 read_point；生成后询问留在当前还是打开新标签页。
- 卡片复习依赖 Spaced Repetition 插件；测试 Vault 已安装 SR 1.15.4，卡片可评分。
- 本阶段不写回 priority / next_review / interval。
