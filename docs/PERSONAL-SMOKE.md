# MemoFlow 个人 smoke checklist

每次较大改动后，在测试 Vault 手动跑一遍。

## 基础

- [ ] 总览能打开，今日计数/队列不报错。
- [ ] `开始今日学习` 能打开第一项实际内容。
- [ ] PDF 来源用 Obsidian 原生 PDF 打开，页码正确。
- [ ] Markdown 来源/摘录顶部有阅读条。

## 剪贴摘录

- [ ] 在 PDF 中复制一段文字。
- [ ] 点 `剪贴摘录`，后台生成摘录。
- [ ] 弹窗出现 `留在当前 / 在新标签页打开`。
- [ ] 选择留在当前，活动标签仍是 PDF。
- [ ] 选择新标签页，摘录在新标签打开。
- [ ] 摘录 `page` 等于当前 PDF 页（或剪贴板 `#page=`）。
- [ ] 新摘录没有黄色 PDF callout 背景。

## 卡片

- [ ] 从摘录制卡（基础问答）。
- [ ] 从摘录制卡（C1/C2）。
- [ ] 卡片复习页能显示答案、评分。
- [ ] SR 缺失/异常时有可理解的回退提示。

## 安全

- [ ] 移出队列/仅标记完成有确认。
- [ ] 完成阅读不会误删笔记。
- [ ] Vault 有 Git/Time Machine 备份。

## 收尾

- [ ] `node --test test/*.test.js` 通过。
- [ ] `node scripts/validate-memoflow.mjs` 通过。
- [ ] 没有需要保留的测试摘录/临时 PDF。
